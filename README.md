# studienmap-legal

This repository hosts the public product, privacy, support, and legal pages for the iOS app **StudienMap**.

The site is deployed via GitHub Pages from the `main` branch root and is available at:  
`https://wichtelimwald.github.io/studienmap-legal/`

## Files

| File | Purpose |
|------|---------|
| `index.html` | Product page — describes what StudienMap is and what it does |
| `privacy.html` | Privacy policy — data handling, iCloud sync, no tracking |
| `support.html` | Support page — FAQ and contact information |
| `style.css` | Shared stylesheet for all pages |
| `README.md` | This file |

## Design principles

- Plain HTML and CSS only — no JavaScript, no frameworks, no build step.
- No external fonts or external assets.
- No cookies, no analytics, no tracking.
- Responsive layout — works on mobile and desktop.
- Semantic HTML and accessible structure throughout.
- System fonts only.
- Centered max-width layout with simple navigation.
